# train.py 백업

`train.py`는 하나뿐이라 학습 방식을 바꾸면 예전 내용이 덮어써진다.
그래서 버전마다 여기에 `train_<날짜_시각>.py`로 남긴다.

- **자동 백업**: `python train.py`를 실행하면 맨 처음에 현재 `train.py`를 가장 최근 백업과 비교한다. 내용이 다를 때만 새 파일로 저장한다. 시드만 바꿔 여러 번 돌릴 때는 새로 만들지 않는다.
- **예전 버전**: 2026-09-07 ~ 11-13 백업은 `results/run_<날짜_시각>/train.py` 중 내용이 다른 것만 모아, 그 run의 시각으로 이름을 붙였다.
- **예전 방식으로 다시 학습하려면**: 원하는 파일을 `train.py`로 복사해서 실행한다. 단, 그 사이에 `env/`의 코드나 설정이 바뀌었을 수 있다.
