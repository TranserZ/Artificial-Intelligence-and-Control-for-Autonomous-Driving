# 베이스라인 PPO (env-v1, 규칙 없음) — 1차 결과

> **한 줄 요약** · env-v1 기본 설정 그대로 PPO(MLP 256×256)를 학습 시드 3개로 43만~49만 step 학습했다(Kaggle 11.5시간 제한으로 100만 step 전에 중단). 테스트 100판(1000~1099, 감시 모드) **완주율 0% (3개 시드 모두)**. 대부분 판이 "신호 앞에서 서 있다가 시간 초과"로 끝났다. 수동개입률(1.3%)이 낮은 것은 잘 달려서가 아니라 서 있어서다.

## 1. 모델

| 항목 | 값 |
|---|---|
| 알고리즘 | PPO, hybrid 정책 (가감속 연속 Normal + 차선 이산 Categorical) |
| 네트워크 | MLP 256×256 ReLU (정책·가치 따로) |
| 하이퍼파라미터 | lr 1e-4, n_steps 2048, epochs 10, minibatch 64, γ 0.99, λ 0.95, clip 0.2, 차선 엔트로피 0.01, 초기 σ 0.61 |
| 학습 step | 목표 100만 → 실제 ts0 47.1만 / ts1 43.0만 / ts2 49.2만 (마지막 체크포인트) |

## 6. 판별 결과 · 실패 원인

CSV: `docs/results/baseline_ppo/ts{시드}_step{300k,final}_shadow.csv` (프로토콜 3-4 필수 컬럼 + `lc_forbidden`, `ped_yield_violations`).

**실패 유형은 두 가지다.**

1. **"서 있기"로 수렴 (6개 중 4개 모델, 시간 초과 96~99%)**
   - 판 1000에서 ts0 최종 모델을 따라가 봤다:
     - 첫 정류장(bs_01)은 19초 만에 정차에 성공했다 (+5).
     - 두 번째 신호(354 m, `joinedS_cluster_n13732389919…`) 정지선 9~11 m 앞에서 맨 앞 차로 선다.
     - 녹색이 19초(주기 90초)씩 여러 번 왔지만 가속하지 않았다. 판이 끝날 때(1200초)까지 그 자리에 있었다.
     - 신호 관측은 정상이었다 (`visible=1`, 색 one-hot이 실제 신호와 일치).
     - 서 있는 동안 차선변경 금지 구간인데 왼쪽 변경 명령(+1)을 계속 낸다. 앞에 차가 없고 정지 상태라 실제로는 바뀌지 않는다.
   - 원인(보상 크기): 서 있으면 적색 동안 0점, 녹색 동안만 −0.15/스텝이다. 판 전체로 약 −70 + 시간 초과 −10 = **약 −80**이다.
     - 반면 달리기 시작한 모델(30만 ts0)은 충돌 43%, 적색 위반 25%였다. 각각 −20이고, 위반 전까지 쌓인 감점도 있다.
     - 학습 초반에는 달리다 실패하는 쪽의 기댓값이 더 나빠 보여서, "움직이지 않기"가 국소 최적이 됐다.
2. **달리다 추돌 (최종 ts1: 충돌 67%)**: 평균 14.9 km/h로 출발은 한다. 하지만 앞차와의 간격을 못 지켜서 판당 0.3 km 안에 추돌한다.

**best 모델 선택 기준(A10)의 허점**: 검증 판 완주가 0%이면 "수동개입률이 가장 낮은 모델"이 best가 된다. 그래서 `ts*_best.pt`가 서 있는 모델(개입률 0%)로 골라졌다. 완주율이 같으면 정차 성공 수 → 주행 거리로 먼저 비교하도록 고쳐야 한다 (아래 8절).

## 8. 현재 한계 / 발전 방향

- **학습량 부족**: 100만 step에 25시간이 걸린다. Kaggle 한 번(11.5시간)으로는 50만도 못 채운다.
  - → 커널을 시드별로 나누거나, `--init`으로 이어서 학습한다.
- **서 있기 국소 최적**: 규칙 없이 처음부터 학습하면 "출발 → 신호 통과"를 우연히 경험하기 어렵다.
  - 녹색 정지 감점을 키우거나, 시간 초과 감점을 충돌과 같은 크기로 키우는 방법이 있다 (보상 축 실험).
  - 모방학습으로 출발점을 주는 방법도 있다 (모방학습 축 실험).
- **best 선택 기준 수정 필요** (위 6절).
- **MLP 한계**: 교수님 피드백과 같다. 신호가 가려지는 부분 관측이라 기억이 있는 모델(GRU)이 필요할 수 있다.
