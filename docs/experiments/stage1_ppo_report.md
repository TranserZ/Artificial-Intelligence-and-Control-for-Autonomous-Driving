# CGC_STAGE 단계별 PPO 커리큘럼 학습 기록 (Stage 1)

## 1. 실험 목적 및 환경
- **브랜치:** model/sunwoo-ppo-stage (origin/env/v3-merge 기반)
- **커리큘럼 단계:** CGC_STAGE=1 (bus_stop 전용 — 청계천로 편도 2차로, 신호·끼어들기·장애물 OFF)
- **핵심 제약 조건:** 전체 커리큘럼 진행 중 **충돌률 5% 이하** 유지 및 버스정류장 정차·완주 기본기 확보

## 2. 보상 가중치 조정 내역 (env/mdp_config.py)
초기 기본 설정에서는 저속 유지 보상이 경로 진행 보상보다 커서 에이전트가 제자리에 머무는 초기 정체 현상(평균속도 0.03~0.7 m/s, 완주율 0%, 정류장놓침 100%)이 발생함. 전진 유인을 강화하고 불필요한 저속 정체를 억제하기 위해 4개 파라미터를 수정함.

| 파라미터 | 기본값 | 수정값 | 변경 의도 및 물리적 의미 |
| :--- | :---: | :---: | :--- |
| speed_weight | 1.0 | 0.0 | 제자리 미세 움직임이나 단순 속도 유지에 대한 편법 보상 제거 |
| progress_weight | 5.0 | 10.0 | 실제 목표 경로를 따라 전진한 거리 비례 보상을 2배 상향하여 출발 유도 |
| green_stop_penalty | 0.0 | 0.08 | 주행 가능 구간에서 불필요하게 감속·정차하는 행동에 지속 페널티 부여 |
| green_stop_extra | 0.0 | 0.15 | 저속 정체(기어가기) 상태가 길어질수록 추가 페널티를 부과해 정체 탈출 유도 |

### 학습 결과의 핵심 의미
1. **안전성(충돌률 0%) 우선 달성:** cgc_stage1_real_200k 평가 기준 충돌률 0%로 핵심 제약 조건(충돌률 <= 5%)을 완벽히 충족함.
2. **롤아웃(탐험 포함) vs 결정론적(Eval) 정책의 괴리:** 300k 추가 학습에서 탐험 노이즈 포함 롤아웃 완주율은 76%까지 상승하고 차선 변경도 6.07회로 안정화되었으나, 결정론적 평가(Eval)에서는 가속 평균이 낮게 수렴하며 0.5 m/s로 기어가는 보수화 현상이 나타남. 따라서 Stage 2 전이 학습(--init)에는 **평가 성능이 검증된 cgc_stage1_real_200k/best_model.pt를 채택**함.

## 4. Stage 1을 60% 완주율에서 마무리하고 Stage 2로 전환하는 이유
1. **단순 환경 과적합(Overfitting) 및 정책 경직 방지:** Stage 1에는 신호등과 횡단보도가 없어 지나치게 오래 학습하면 전방 신호와 무관하게 직진하는 정책에 과적합되거나, 300k 사례처럼 정책 분산(std)이 축소되며 평가 속도가 급감하는 경직 현상이 발생함.
2. **하위 과업(버스정류장 정차)의 병렬 누적 학습:** CGC_STAGE=2는 bus_stop(정류장) 위에 signal(신호·횡단보도)을 누적 활성화한 환경이므로, Stage 2 학습 중에도 정류장 정차 기본기는 계속 반복 훈련되며 신호 대응 능력을 병렬로 습득함.
3. **사전 학습 가중치(--init)를 통한 안정적 전이:** 초기부터 Stage 2를 학습하면 정류장 정차와 신호 정차를 동시에 탐색하다 초기 정체(완주율 0%)로 빠질 위험이 큼. 이미 출발-주행-정류장 정차 표현이 형성된 best_model.pt를 초기값으로 사용해 기존 능력을 보존한 채 확장함.

## 5. 재현 및 Stage 2 실행 명령어
- Stage 1 재현: `$env:CGC_STAGE=1; python train.py --timesteps 200000 --seed 0 --run-name cgc_stage1_real_200k`
- Stage 2 전이 학습: `$env:CGC_STAGE=2; python train.py --init results\cgc_stage1_real_200k\best_model.pt --timesteps 200000 --seed 0 --run-name cgc_stage2_200k`
