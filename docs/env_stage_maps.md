# 청계천로 단계별 도로 환경 (6단계) — 최종 정리

> **한 줄 요약** · 같은 청계천로(청계광장 → 청계4가, 2.1 km) 위에 요소를 하나씩 더한 **도로 6개**를 만든다. 뒤 단계는 앞 단계 요소를 모두 포함한다. **도로마다 기준을 넘은 "학습 성공" 모델을 하나씩 만든다.** 모델이 보는 관측(67개)과 기록 파일(167칸)은 6개 도로에서 모두 같다.

| 작성일 | 브랜치 | 기준 커밋 |
|---|---|---|
| 2026-11-21 | `env/simplified_road_config` | 이 문서를 넣은 커밋 |

**이 문서 읽는 순서**: 1. 6개 도로 → 2. 모든 도로에 공통인 것 → 3. 요소별 구현 → 4. 학습과 연결되는 부분 → 5. 검증 결과 → 6. 실행 방법 → 7. 확정된 학습 방식 → 8. 남은 일

## 3. 요소별 구현

### 3-1. 버스정류장 (1단계~)
- 노선 정류장 5곳: 청계광장 · 청계1가.광교 · 청계2가.삼일교(동) · 청계3가.관수교(동) · 청계4가.배오개다리 (`config/lines.yaml`)
- **정차 성공**: 정류장 구간의 정류장 차로에서 0.1 m/s 이하로 10초 이상 서 있음. 지나치면 놓침
- SUMO에 정차를 맡기지 않는다. 모델이 직접 서야 한다 (규칙 금지)

### 3-2. 신호등·횡단보도 (2단계~)
- 경로 위 신호 6곳. 버스 방향의 녹·황·주기를 실측에 맞춘다 (`data/road_data/signal_timing.csv`, `tools/signal_plans.py`)

| 교차로 | 주기 | 버스 방향 녹 / 황 | 출처 |
|---|---|---|---|
| 무교로 (청계광장 동쪽) | 139 s | 55.5 / 4.3 | 광교 값 차용 (API에 보행 신호만 있음) |
| 광교 (남대문로) | 139 s | 55.5 / 4.3 | **T-DATA API 실측** (21835) |
| 청계2가 (삼일대로) | 170 s | 72 / 3 | 교통영향평가 2025 (방향 추정) |
| 수표교 (수표로) | 139 s | 55.5 / 4.3 | 광교 값 차용 (자료 찾는 중) |
| 청계3가 (충무로) | 130.6 s | 32.6 / 4.4 | **T-DATA API 실측** (23331) |
| 청계4가 (창경궁로) | 140 s | 42 / 3 | 교통영향평가 2022 (방향 추정) |

- 신호 횡단보도와 보행자(시간당 400명, 걸어갈 수 있는 출발·도착 24쌍)는 2단계부터 나온다
- 1단계에는 신호와 횡단 보행자가 모두 없다 → 정류장 정차에만 집중

### 3-3. 끼어들기 (3단계~)
- 옆 도로 7곳에서 본선으로 합류하는 차(`cutin_car`, 곳당 시간당 40대) + 세종대로 합류(시간당 60대)

### 3-4. 어린이보호구역 (4단계~)
- 세운상가 앞 엣지 3개 (`e218924602_1~3`), 경로 1,335~1,597 m (로드뷰 1,333~1,610 m)
- 제한속도 20 km/h. 노면 표시(빨간 노면, "20" 표지)는 화면에 보임
- 인도: 20 km/h 엣지에서도 인도가 생기도록 netconvert `--sidewalks.guess.min-speed 1` (동연 님 수정)

### 3-5. 오토바이 (5단계~)
- 시간당 120대. 차선변경 성향 `lcSpeedGain=8` → km당 차선변경 2.11회 (일반 차 1.40회의 **1.50배**, 1시간 × 시드 3개 측정)
- 오토바이 관련 충돌 경고 0건
- 노상 주차 오토바이 14대: 판 시작부터 300초 동안 연석 쪽에 서 있다가 차로로 나와 떠난다. 움직이는 오토바이가 되므로 5단계부터만 둔다

### 3-6. 불법주정차 (6단계, 2026-11-21 확정)
- 로드뷰 다발지점 4곳. 판마다 지점별 70% 확률로 정류장 차로를 막고 선다 (`data/road_data/illegal_parking_hotspots.csv`)

| 지점 | 차량 |
|---|---|
| 삼각동 한빛공원 앞 | 승용차 1대 |
| 청계2가 동쪽 (bs_03 뒤) | 이륜차 2~3대 |
| 입정동 공구상가 앞 | 이륜차 3~5대 |
| 주교동 기계상가 앞 | 이륜차 3~4대 + 화물차 1대 |

## 4. 학습과 연결되는 부분

### 4-1. 관측 67개 (모든 단계 같음)
| 버스가 알고 싶은 것 | 칸 수 |
|---|---|
| 내 속도 | 1 |
| 주변 차 (5개 차로의 앞차·뒤차, 밀도, 차로 끝) | 30 |
| 갈 수 있는 방향 (회전 안내, 노면 화살표) | 18 |
| 신호 (거리, 색, 보이는가) | 6 |
| 횡단보도 보행자 (2곳) | 6 |
| 정류장 (거리, 차로 차이, 서 있은 시간) | 3 |
| 보호구역 (2), 차선변경 금지 구간 (1) | 3 |

- 꺼진 요소는 칸을 지우지 않고 "없음" 값으로 채운다. 그래서 앞 단계 모델을 다음 단계에 그대로 이어 학습할 수 있다
- 행동을 고르는 시간은 0.6 ms(입력 20·67·200개 모두 0.43 ms 안팎)이고, 한 스텝 계산 9.7 ms 중 약 6%다 → 관측 수 때문에 행동이 느려지지 않는다
- 컬럼 정의: `docs/data_columns.md`

### 4-2. 판이 끝나는 경우
| 종료 | 내용 |
|---|---|
| 도착 | 노선 끝 도달. **완주 = 도착 + 정류장 놓침 0** |
| 충돌 | 차량·보행자 충돌, 즉시 종료 |
| 적색 위반 | 적색에 정지선 통과, 즉시 종료 |
| 차로 오류 | 경로로 이어지지 않는 차로 끝에 갇힘 |
| 시간초과 | 1,800초 |

### 4-3. 기록 파일 167칸 (모든 단계 같음)
식별 4 + 관측 67 + 행동 6 + 보상·종료 3 + 사건 16 + 3인칭 상태 71. 신호가 없는 1단계는 신호 칸 42개가 모두 −1이다.

| 지형 | 노선 길이 −0.4%, 차로 수 24/24, 노선 지점 7곳 중 5곳 양호 (광교 −28 m, 삼일대로 −22 m). 허용 이유: `docs/reports/2026-11-21_청계천로_지형오차_요약.md` |
| 속도 | 모든 차량 8.33 m/s(30 km/h) 이하 확인 |

## 6. 실행 방법

```bash
# 3단계 도로로 학습 (도로는 학습 시작 때 자동 생성)
CGC_STAGE=3 python train.py --run-name stage3

# 앞 단계 성공 모델에서 이어 학습
CGC_STAGE=4 python train.py --init results/stage3/best_model.pt --run-name stage4

# 화면으로 보기 (데모 버스가 스스로 달림)
CGC_STAGE=6 python view_road.py
```

## 7. 확정된 학습 방식 (2026-11-21)

| 항목 | 결정 |
|---|---|
| 학습 방식 | 도로마다 "학습 성공" 모델을 하나씩 만든다. **각 도로는 앞 도로의 성공 모델에서 이어 학습**한다 (1단계만 처음부터) |
| 성공 기준 (안) | 팀 가이드 목표: 검증 판 완주율 95% 이상 + 수동개입률 16% 이하 |
| 정류장 보상 | 정차 성공 +5, **놓침 −20** (충돌·적색 위반과 같은 크기. `env/v3-prep`과 같음) |
| 불법주정차 | 6단계로 **확정** |
| 주차 오토바이 | 오토바이가 들어가는 **5단계부터** |

**수동개입률**: 감시 모드(shield가 운전에 손대지 않고 "개입했을지"만 기록)로 테스트했을 때, 전체 주행 step 중 shield가 개입했어야 하는 step의 비율. 실제 버스의 안전요원이 브레이크를 밟아야 했던 시간 비율에 해당한다. 16%는 실제 청계 셔틀 수치다 (단위 확인 중, `experiment_protocol.md`).

## 8. 남은 일·알아둘 점

1. **수표교 신호**: T-DATA MAP 목록을 페이지별로 받는 중 (6시간에 1페이지)
2. **성공 기준 확정**: 위 안을 팀과 확정
3. **브랜치**: `env/v3-prep`(동연 님)이 이 브랜치의 11-21 새벽 버전을 합쳐 다음 공통 환경을 준비 중이다. 이후 수정(버스 속도 상한 버그, 청계3가 신호, 기록 파일 칸 고정, 주차 오토바이 단계)은 v3-prep에 아직 없다

### 이 브랜치에서 고친 버그 (main에도 있음)
| 버그 | 영향 | 수정 |
|---|---|---|
| 엣지 모양에 양 끝점이 빠짐 | 교차로 안 구간이 761 m로 부풀어 위치가 어긋남 | `tools/osm_to_sumo.py` (→ 428 m) |
| 버스 속도 상한이 50 km/h | speedMode=0이라 SUMO가 최고속도를 안 지킴. 셔틀 40 km/h 설정도 무시됨 | `env/sumo_env.py` `ego_vmax` |
| 20 km/h 엣지에 인도 없음 | 보행자가 버스 차로를 걸음 (4단계~) | `env/road_builder.py` (동연 님) |
