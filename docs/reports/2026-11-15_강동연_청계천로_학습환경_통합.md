## 왜 했나
천호사거리에서 학습한 모델을 청계천로에 그대로 돌리면 **40판 중 39판 충돌**. 청계천로에서 학습해야 하는데, 그 전에 도로(희영님)와 학습 코드(민기님)를 하나로 합쳐야 했다.

## 한 일
- **도로 합치기**: 희영님 `feature/huiyoung-oneway` (정류장 11곳, 실제 차로 수, 어린이보호구역, 정차금지지대, 오토바이·트럭 주정차, 자전거, 왕복 노선) + 신호 6곳 + 민기님 최신 학습 코드
- **정류장 정차 = 규칙(상위), 주행 = 학습 모델(하위)**
  - 300 m 전부터 맨 오른쪽 차로로 옮기고, 정류장에서 편한 감속(1.5 m/s²)으로 섬, 15초 정차
  - 정차 중에는 보상 0 (정차는 규칙이 정하니까 모델 책임이 아님)
- **차량 안전 필터**: 앞차와 너무 가까워질 가속은 브레이크로 바꿈. 필터가 개입하면 작은 감점 → 필터 없이도 안전하게 달리도록 유도
- 모델 입력 44개 (정류장까지 거리, 정차 중 추가). 예전 모델(40개)도 이어서 학습 가능

## 고친 버그
| 증상 | 원인 | 수정 |
|---|---|---|
| 버스가 정류장 옆 차로에서 영원히 멈춤 | 정류장을 다른 차로로 지나치면 SUMO가 엣지 끝에서 세워 둠 | 지나친 정류장은 건너뛰고 기록 |
| 정류장 차로로 못 옮김 | 모델의 "차로 유지" 명령이 이동을 취소 / 직선도로용 변경 금지 규칙(입구 60 m) | 정류장 구간에선 규칙이 차로 담당, 청계천로는 20 m |
| 관수교 정류장에 못 섬 | 엣지가 14.8 m로 짧아져 12 m 버스가 설 자리 없음 | 다음 엣지로 이어서 배치 |
| 버스가 출발을 못 함 | 입구 1차로가 자전거·오토바이로 막힘 | 진입 대기 15초 → 100초 |

## 결과
| 항목 | 결과 |
|---|---|
| 규칙 운전 8판 | 충돌 0, 정류장 놓침 0 |
| 배경 교통 30분 × 4번 | 순간이동·충돌·오류 0 |
| 민기님 모델 (재학습 없음) | **이전: 40판 중 충돌 39 → 지금: 10판 중 완주 7, 충돌 0** (나머지 신호위반 2, 시간초과 1) |

## 학습 (Kaggle, 진행 중)
- 민기님 11/08 모델에서 이어 학습, 시드 3개 동시, 각 100만 스텝
- 근거: 다른 교차로에서 미리 학습한 모델을 이어 학습하면 처음부터보다 낫다는 연구, 안전 필터(shield)를 학습 중에도 켜는 방식, 시드 여러 개로 운 영향 확인

## 남은 일
- 학습 끝나면 100판 평가 (완주율, 충돌, 신호위반, 정류장 정차, 평균 속도)
- 신호 주기·정차 시간은 추정값 → 실제 값 들어오면 교체
