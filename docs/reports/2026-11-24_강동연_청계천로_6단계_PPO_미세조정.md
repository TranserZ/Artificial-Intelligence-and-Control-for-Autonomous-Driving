# 청계천로 6단계 PPO 미세조정 (적색 벌점 강화)

> **한 줄 요약** · 11-23 관측 보강 모방학습 학생(67.8%)을 PPO로 다듬음. 적색 벌점 20 → 60, 시드 1 → **완주 70.0%·충돌 7.8%** (`s6_student_ppo.pt`). 충돌은 22% → 8%로 크게 줄었지만 **적색 통과가 2% → 18%로 늘었다** (적색 벌점을 3배로 해도 그대로). 데이터 전부 모아 다시 BC는 61.1%로 실패.

## 결과 (90판, 관측 보강 `OBS_SCAN=1`)

| 시도 | 완주 | 충돌 | 적색 | 시간초과 |
|---|---|---|---|---|
| 출발점: BC2 (`s6_student_obsfix.pt`, 11-23) | 67.8% | 22.2% | 2.2% | 7.8% |
| BC2 + 선생님 v4 DAgger 1회 + 지금까지 시범·DAgger 전부로 BC (`kaggle/s6agg.py`) | 61.1% | 7.8% | 6.7% | 24.4% |
| BC2 → PPO 미세조정, 적색 벌점 60, 시드 0 | 66.7% | 11.1% | 17.8% | 4.4% |
| **BC2 → PPO 미세조정, 적색 벌점 60, 시드 1 (`s6_student_ppo.pt`, `kaggle/s6ft2.py`)** | **70.0%** | **7.8%** | 17.8% | 4.4% |

- PPO 미세조정: `teacher56.py finetune` (`REWARD_RED=60`), init BC2, 시범 = 관측 보강 데이터(BC 항, bc-coef 1, 줄이지 않음), 200k step, lr 3e-5, 약 50k step마다 검증 20판으로 best 저장
- **충돌 22% → 8%**: PPO가 서 있다가 무리하게 끼어드는 걸 덜 하게 됐다
- **적색 통과 2% → 18%**: PPO가 더 빨리 달리면서 황색에 들어가는 쪽으로 바뀜. 적색 벌점 20 → 60으로 올려도 그대로 → 원인 분석은 [11-25 실패 진단](2026-11-25_강동연_청계천로_6단계_실패진단.md)
- best 저장 기준이 완주율 우선(충돌은 동점일 때만)이고 검증 20판이라 운에 많이 흔들린다
- 데이터 전부 BC: 충돌은 줄었지만 멈춰 서서 시간초과 24% → 실패

## 한계

- 적색 통과가 남은 실패의 대부분 (18%)
- 이 모델도 보강된 관측으로만 제대로 달린다 (공식 평가에는 env `_neighbor` 수정 필요, 팀 결정)

## 재현

```
CGC_STAGE=6 OBS_SCAN=1 REWARD_RED=60 TEACHER_AVOID=1 BCPPO_YELLOW_DECEL=2.4 \
python models/dongyeon_bc/teacher56.py finetune --data <관측 보강 시범·DAgger npz> --init s6_student_obsfix.pt --out ft_s1 \
    --seed 1 --steps 200000 --bc-coef 1.0 --warmup-steps 10000 --decay-steps 100000000 --lane-bc-coef 1.0 --lr 0.00003 --replay-prob 0.3
CGC_STAGE=6 OBS_SCAN=1 BCPPO_YELLOW_DECEL=2.4 python models/dongyeon_bc/teacher56.py eval \
    --ckpt models/dongyeon_bc/s6_student_ppo.pt --shield shadow --episodes 15 --seed-base 900100
```
