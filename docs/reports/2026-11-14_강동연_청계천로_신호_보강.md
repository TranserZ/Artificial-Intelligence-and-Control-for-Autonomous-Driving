## 왜 했나
지도 데이터(OSM)에 신호 표시가 거의 없어서 2.1 km 동안 빨간불이 한 번(남대문로)밖에 안 나왔다. 실제 청계천로는 큰길과 만날 때마다 신호가 있으니, 이대로면 "신호 지키기"를 제대로 배울 수 없다.

## 한 일
- 기준: **청계천로가 큰길(간선도로)과 만나는 교차로 = 신호교차로**
- 신호 6곳: 무교로 · 남대문로 · 삼일대로 · 수표로 · 충무로 · 창경궁로(배오개다리)
- 삼일대로처럼 교차로가 여러 덩어리로 쪼개진 곳은 신호 하나로 묶음
- 빨간불 급정거 때 끼어들기 차들끼리 추돌하던 것 수정 (반응 시간 0.8초 → 1.0초)
- 신호가 늘어 주행 시간이 길어져서 청계천로 에피소드 600초 → 900초

## 결과
| 항목 | 전 | 후 |
|---|---|---|
| 경로 위 신호 | 1곳 | **6곳** |
| 규칙 운전 8번 | 8번 도착 | 8번 도착, 빨간불 위반 0 · 충돌 0 |
| 30분 시뮬레이션 6번 | 문제 0 | 순간이동 · 충돌 · 오류 0 |

## 남은 일
- 신호 위치·주기는 추정값 → 로드뷰/현장으로 확인하면 더 좋음
- 버스정류장 11곳, 청계천로 어린이 보호구역
