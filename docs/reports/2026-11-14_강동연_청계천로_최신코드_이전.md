## 한 일
- `school_zone`(관측 42차원) 위에 청계천로 연결 커밋을 옮김 (충돌 없이 합쳐짐)
- 청계3가 부근 합쳐진 교차로에서 버스가 일반 차량과 충돌하던 문제 수정
  - 원인: 추가한 직진 연결(1→1)이 기존 대각선 연결(2→1)과 교차로 안에서 합류
  - 조치: 직진 연결을 추가할 때 같은 목표 차로로 들어가는 대각선 연결 제거

## 검증
- 규칙 운전 8회 모두 도착, 충돌 0
- 배경 교통 30분 × 6회: 순간이동·보행자 정체·충돌·오류 0

## 남은 과제
- 어린이 보호구역은 천호사거리 전용 → 청계천로 실제 위치에 적용 필요 (지금은 관측값 0)
- 버스 경로 위 신호 보강, 버스정류장 11곳
