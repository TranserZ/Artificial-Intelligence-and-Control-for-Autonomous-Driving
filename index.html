개요

Overview

청계A01은 청계광장과 광장시장 사이 청계천로를 운행하는 서울시 자율주행버스입니다. 차량은 운전석이 없는 8인승 셔틀 ROii이고 시속 20 km 안팎으로 다닙니다. 운행 1년 동안 다른 차가 끼어들어 접촉 사고가 났고, 지금도 사람이 개입해야 하는 상황이 남아 있습니다.

이 프로젝트의 목표는 사람의 개입을 줄여, 미국 자동차기술자협회(SAE)가 정한 자율주행 레벨 4(정해진 구역 안에서 사람이 개입하지 않아도 되는 고도 자동화)에 다가가는 모델을 만드는 것입니다.

청계A01의 동쪽 방향 구간(청계광장 → 광장시장 앞, 2.1 km)을 교통 시뮬레이터 SUMO로 만들었습니다. 도로 형상은 OpenStreetMap에서, 차로 수는 로드뷰 조사에서, 신호 주기는 서울시 T-DATA 실측값(2곳)과 교통영향평가 자료(2곳)에서 가져왔고, 자료가 없는 2곳은 광교 값을 넣었습니다.

같은 도로에 정류장, 신호, 끼어들기, 어린이보호구역, 오토바이를 차례로 추가해 1단계부터 5단계까지 환경을 만들고, 단계마다 버스 주행 모델을 학습했습니다. 학습에는 규칙 기반 전문가의 주행을 따라 하는 모방학습을 썼고, 5단계 최종 모델은 모방학습 모델을 PPO로 미세조정했습니다.

아래 표는 5단계 최종 모델의 결과입니다. 판은 seed 하나로 한 번 주행한 기록이고, 완주는 종점에 도착하고 정류장 5곳에 모두 정차한 판입니다.

도로 환경

Road

청계천로는 청계천 양쪽의 일방통행 도로입니다. 버스의 동쪽 방향 경로는 엣지(도로 구간) 24개, 길이 2,137 m이고 로드뷰로 잰 2,146 m와 0.4% 차이입니다. 차로 수는 구간에 따라 1~3차로(대부분 2차로)이고, 로드뷰 조사표와 비교해 엣지 24개 모두 맞췄습니다.

가정한 값

  • 교통량과 보행량은 실측 자료를 구하지 못했습니다. 일반 차량은 본선 시간당 400대, 보행자는 시간당 400명으로 정했습니다.
  • 일반 차량의 주행 모델은 수업 기본 설정과 같이 Krauss 35%, IDM 30%, EIDM 20%, ACC 15%로 섞었습니다.
  • 모든 차량의 최고 속도는 시속 30 km입니다.
  • 버스 크기는 ROii 제원(길이 4.9 m, 폭 2.1 m)이고, 가속 1.0 m/s², 감속 2.5 m/s²는 가정한 값입니다.

단계별 환경

Stages

같은 도로에 요소를 하나씩 추가했고, 뒤 단계는 앞 단계의 요소를 모두 포함합니다.

관측 67차원은 다섯 단계에서 같습니다. 그 단계에 아직 없는 요소의 칸도 비워 두지 않고 “해당 없음” 값으로 채웁니다. 예를 들어 1단계에는 신호가 없지만 신호 칸 6개는 “보이는 신호 없음” 값으로 들어갑니다. 입력 크기가 늘 같아서, 앞 단계에서 학습한 모델을 다음 단계 학습의 출발점으로 그대로 쓸 수 있습니다.

  1. 1

    버스정류장

    정류장 5곳, 승객 6명

    정류장 차로에서 10초 연속 서 있으면 정차 성공이고, 정류장 끝을 지나치면 놓친 것으로 처리합니다. SUMO의 자동 정차 기능이나 대신 세워 주는 규칙은 쓰지 않고, 모델이 직접 차로를 옮기고 섭니다.

  2. 2

    신호등, 횡단보도

    신호 6곳(주기는 위 표), 보행자 시간당 400명

    적색에 정지선을 넘으면 그 판은 바로 종료됩니다. 횡단보도를 건너는 보행자에게 양보해야 합니다.

  3. 3

    끼어들기

    측면 합류 7곳(각 시간당 40대), 세종대로 합류 1곳(시간당 60대)

    옆 도로에서 본선으로 합류하는 차량이 추가됩니다. 실제 청계A01의 사고 유형과 같은 상황입니다.

  4. 4

    어린이보호구역

    세운상가 앞 약 260 m, 제한 20 km/h

    구간 안에서 시속 20 km 이하로 주행해야 합니다.

  5. 5

    오토바이

    시간당 120대, 노상 주차 오토바이 14대

    오토바이는 일반 차량보다 차선을 1.5배 자주 바꾸도록 설정했습니다(km당 2.11회, 일반 차량 1.40회).

위 주행 영상(5단계 최종 모델, seed 900377)에서 잘라 낸 장면입니다. 초록색 차량이 버스입니다.

학습 방법

Training

처음에는 PPO만으로 학습했습니다. 베이스라인 PPO는 테스트 100판에서 한 판도 완주하지 못했습니다. 학습이 진행될수록 신호 앞에서 멈춘 뒤 다시 출발하지 않게 됐습니다. 움직이다 충돌하면 크게 감점되고 서 있으면 감점이 작아서, 서 있는 것을 가장 손해가 적은 행동으로 배운 것입니다. 보상 항목을 줄인 실험에서도 첫 정류장에 정차한 뒤 출발하지 않았습니다. 보상을 조정해 단계별로 다시 학습한 PPO도 정류장만 있는 1단계에서 완주율 60%가 최고였습니다(아래 “1단계 방법 비교” 표의 PPO와는 보상 설정이 다른 실험입니다).

이후 모방학습으로 바꿨습니다. 규칙으로 주행하는 전문가를 만들고, 전문가의 주행 데이터로 학생 모델을 학습하는 방식입니다.

  1. 전문가PPO 정책에 안전 필터와 규칙을 더한 것입니다. 정류장 150 m 전부터 정류장 차로로 옮겨 10초 정차하고, 적색과 황색에서 미리 감속하고, 보호구역에서는 제한속도보다 낮게 주행합니다. 속도 규칙은 정책의 가감속을 낮추는 방향으로만 작동합니다.
  2. 시범 수집전문가로 시범 주행을 수집합니다(1단계와 5단계 기준 100판). 충돌이나 위반이 있는 판은 제외하고, 필터와 규칙이 적용된 뒤의 행동을 정답으로 저장합니다.
  3. 모방학습 (BC)학생은 관측 67차원을 입력받는 MLP(256-256)이고 가감속과 차선변경을 출력합니다. 앞 단계 학생의 가중치에서 시작해 시범 데이터로 학습합니다.
  4. DAgger학생이 주행하며 만난 상태에 전문가의 행동을 붙여 데이터에 추가합니다. 1, 2단계 최종 모델에 적용했고, 3단계부터는 최종 모델에 쓰지 않았습니다. 5단계에서는 적용했을 때 충돌이 6.7%에서 11.1%로 늘었습니다.

평가에서 학생은 규칙과 안전 필터 없이 주행합니다. 안전 필터는 개입 여부만 기록하는 감시 모드로 둡니다.

전문가, BC, BC + DAgger는 개발 판 30개 기준이고, PPO가 들어간 두 줄은 학습 중 검증 판 기준입니다(범위는 시드별 값). BC 모델을 PPO로 이어서 학습하면 대부분 완주율이 떨어졌습니다.

BC 모델의 PPO 미세조정 실험 (4단계)

4단계 BC 모델에서 시작해, PPO를 더해도 BC가 배운 주행이 무너지지 않는지 확인하기 위해 KL 페널티(BC 모델의 행동에서 멀어지면 벌점)를 준 PPO 미세조정을 30만 step 학습했습니다. 앞서 BC 모델에 PPO를 그대로 이어 학습했을 때 주행이 무너졌기 때문에, 이미 잘 달리는 4단계에서 안정성부터 확인한 것입니다. 10만 step 체크포인트는 개발 판 30개에서 완주 100%, 충돌 0%를 유지했고, KL 페널티를 끄고 차선 고정도 푼 대조군은 30만 step에서 완주 76.7%(종점 도착 80%), 충돌 20%로 무너졌습니다. KL 페널티를 준 쪽도 학습을 더 진행한 30만 step에서는 학습 시드 0이 완주 83.3%로 내려가(시드 1은 96.7%), 중간 체크포인트를 골라 쓰는 방식이 필요했습니다.

5단계 최종 모델 (BC 후 PPO 미세조정)

최종 모델은 5단계 BC 모델(s5_student.pt)에서 시작해 같은 방식으로 PPO를 30만 step 더 학습한 것입니다. KL 페널티 계수는 0.1에서 시작하고 하한은 0.01입니다. 차선변경 출력은 BC 모델의 것을 그대로 두고 가감속만 학습했습니다. 보상에서 속도 항은 뺐고, 가치 신경망은 정책과 분리했습니다. 학습률은 정책 1e-5, 가치 1e-4, 할인율은 0.99입니다.

평가와 데이터 수집에는 25만 step 체크포인트(step250k.pt)를 썼습니다. 개발 판 30개에서는 완주 86.7%(종점 도착 93.3%), 충돌 1판이었고, 학습에 쓰지 않은 평가 판 100개에서는 완주 84%(종점 도착 87%), 충돌 3%였습니다.

결과

Results

과제 기준은 충돌률 5% 미만과 종점 도착이고, 팀 기준은 완주율 85% 이상, 개입률 16% 이하입니다. 완주는 종점에 도착하고 정류장 5곳에 모두 정차한 판이고(저장소 문서의 “완벽 완주”), 종점 도착은 놓친 정류장이 있어도 종점까지 간 판입니다(“공식 완주”). 충돌에는 보행자 충돌을 포함하고, 개입률은 감시 모드의 안전 필터가 개입 조건에 해당한 step의 비율입니다.

한계

Limitations

아래 그림은 최종 모델이 평가 100판 중 실패한 13판에서 주행이 끝난 위치입니다(종점에 도착했지만 정류장을 놓친 3판은 제외). 광교 교차로 안에서 멈춘 시간초과가 6판으로 가장 많습니다.

  • 5단계 최종 모델의 완주율은 평가 100판 84%, 데이터 수집 6,000판 81.0%로 팀 기준 85%에 못 미칩니다. 종점 도착은 각각 87%, 86.0%이고, 그 차이는 정류장을 놓친 판입니다.
  • PPO 미세조정의 효과는 100판으로는 확인되지 않았습니다. 같은 평가 판에서 BC 모델은 완주 86%, 충돌 2%, 최종 모델은 완주 84%, 충돌 3%입니다.
  • 최종 모델은 평가 100판 중 63판에서 60초 이상 멈춘 구간이 있었습니다(저장소 README 기준, 맥에서 다시 돌린 재평가에서는 64판). 이 수는 정지선 앞 적색 대기를 이미 뺀 것이고, 황색 대기와 신호 대기열까지 빼고 다시 세면 19판입니다. 이동 중 평균 속도는 시속 19.6 km, 정지 시간을 포함하면 시속 10.9 km입니다(11-26 재평가 보고서).
  • 같은 100판에서 어린이보호구역 안 과속 step은 0.9%였고(최대 초과 2.0 m/s), 횡단보도 양보 위반은 1 step이었습니다. 보호구역 과속은 최종 모델의 보상에 들어 있지 않습니다.
  • 시간초과 7판은 모두 교차로 안에서 정지한 뒤 다시 출발하지 않은 경우입니다. 광교 교차로에서 6판, 청계3가 교차로에서 1판입니다.
  • 모델은 매 순간의 관측만 보기 때문에 황색이 언제 켜졌는지 모릅니다. 신호위반 3판은 모두 정지선 앞에서 감속이 늦은 경우입니다.
  • 팀 기준은 학습 시드 3개의 평균으로 판정하게 되어 있지만, 위 결과는 모두 학습 시드 1개로 얻은 값입니다.
  • 학생 성능은 전문가 시범에 의존합니다. 5단계 시범에서는 전체 스텝의 약 50%에서 안전 필터가 행동을 수정했습니다.
  • 교통량과 보행량은 가정한 값입니다. 무단횡단과 자전거는 환경에 없습니다.

프로젝트 진행 과정

Process

팀원 네 명 모두 강화학습(PPO)으로 시작했습니다. 실패한 이유를 확인한 뒤에는 PPO 보강, 모방학습(BC), 모방학습 후 PPO 미세조정의 세 갈래로 나누었고, 각자의 결과를 다음 학습에 참고했습니다.

DAgger
BC 모델이 운전하다 만난 상황에 전문가의 정답을 붙여 다시 배우는 방법. 모델이 실수하는 장면을 보강.
미세조정(KL 페널티)
이미 학습한 BC 모델을 PPO로 조금 더 학습하되, 원래 행동에서 너무 멀어지지 않게 벌점을 주는 방법. KL 발산은 두 행동 분포가 얼마나 다른지 재는 값. 기존 연구(VPT, InstructGPT)에서 쓰인 방식을 버스 주행에 적용.
할인율(γ)
나중에 받을 보상을 지금 얼마나 반영할지 정하는 값. 작을수록 가까운 미래만 봄.
어텐션 정책
주변 차, 신호, 정류장 중 지금 중요한 것에 더 집중하도록 만든 신경망 구조.

데이터셋

Dataset

한 행이 한 step(0.5초)의 transition입니다. 과제 기준은 107개 이상입니다. 1~4번 8,000판과 2번 추가 1,000판을 합쳐 9,000판, 13,082,875개를 모았습니다. Hugging Face에 담당 번호별 폴더(seed1~seed4)로 모두 올라가 있고, 2번 추가분은 seed2 폴더에 함께 들어 있습니다. 3번과 2번 추가분은 6,000판 결과 집계 뒤에 올라와 결과 표에는 넣지 않았고, 9,000판 전체 수치는 아래 표 밑에 적었습니다.

실행 방법

How to run

Python 3.13, PyTorch, SUMO 1.27.1이 필요합니다. SUMO_HOME을 SUMO 설치 폴더로, PYTHONPATH를 그 안의 tools 폴더로 설정한 뒤 저장소 루트에서 실행합니다. 5단계 환경은 CGC_STAGE=5 OBS_SCAN=0을 붙여야 합니다.

git clone https://github.com/TranserZ/Artificial-Intelligence-and-Control-for-Autonomous-Driving.git
cd Artificial-Intelligence-and-Control-for-Autonomous-Driving
python3.13 -m venv .venv && .venv/bin/python -m pip install -r requirements.txt && source .venv/bin/activate

# 최종 모델로 한 판 주행 (결과 요약 출력)
CGC_STAGE=5 OBS_SCAN=0 python evaluation/drive_parallel.py --model results/klppo1_s5_s0/step250k.pt --seeds 900300 --shield shadow --workers 1

# 평가 판 100개 (결과 표의 5단계 줄)
CGC_STAGE=5 OBS_SCAN=0 python evaluation/drive_parallel.py --model results/klppo1_s5_s0/step250k.pt --seeds 900300-900399 --shield shadow --workers 4

# SUMO-GUI로 한 판 보기
CGC_STAGE=5 OBS_SCAN=0 python evaluation/gui_drive_seed.py --stage 5 --seed 900377 --checkpoint results/klppo1_s5_s0/step250k.pt --delay 80

# 데이터 한 판 수집 (1,021행, 167열)
CGC_STAGE=5 OBS_SCAN=0 python data_collection/collect_pomdp_data.py --model results/klppo1_s5_s0/step250k.pt --seed 5000000 --episodes 1 --workers 1 --name s5_check
