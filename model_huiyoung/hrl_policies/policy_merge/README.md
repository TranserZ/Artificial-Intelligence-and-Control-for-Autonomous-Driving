# policy_merge (추후 학습 — 아직 미구현)

- **상황**: 세종대로 등 측면 도로가 본선으로 합류하는 구간(`through_merge_*`,
  `side_*` flow). 발표 자료의 "접촉사고 원인 ①" 재현 시나리오.
- **계획된 학습 방법**: PPO. 합류 차량과의 틈 타이밍 판단이 규칙 기반으로는
  거칠어서(속도만 보고 급정거/급가속) 순수 PPO로 처음부터 학습하는 쪽이
  낫다고 판단.
- **데이터 소스 후보**: `data_huiyoung/trajectories/`에서 합류 엣지 근방
  구간만 추출해 보상 재설계(끼어들기 양보/추월 성공률) 후 학습.
- **상태**: TODO. `scripts/evaluate_all.py`로 민기 모델의 합류 구간 실패율을
  먼저 정량화한 뒤 착수 여부를 결정한다.
